# 📚 BookShare - ร้านหนังสือ & เช่ายืมออนไลน์ (Warm Earth Tone)

**BookShare** เป็นเว็บแอปพลิเคชันสำหรับชุมชนนักอ่านและการแบ่งปันหนังสืออย่างยั่งยืน ทั้งการเช่ายืมและซื้อขายหนังสือมือสอง ดีไซน์โทนสีอบอุ่น **Warm Earth Tone Minimal** (ครีม, น้ำตาลโกโก้, เขียว Sage) ฟอนต์ Mali & Kanit ใช้งานง่าย สะอาดตา

---

## ✨ ฟีเจอร์หลักในระบบ (Key Features)

1. **หน้าแรก & สำรวจหนังสือ (Home & Explore)**:
   - แบนเนอร์ความคุ้มค่าและสถิติชุมชน (12,500+ เล่ม, 3,200+ ผู้แบ่งปัน, 4.9★)
   - ตัวกรองหมวดหมู่ยอดนิยม: วรรณกรรม & นิยายแปล, จิตวิทยา & พัฒนาตนเอง, ธุรกิจ & การลงทุน, ฯลฯ
   - แคตตาล็อกหนังสือ 8 เล่ม พร้อมป้ายสถานะ `🟢 พร้อมให้ยืม`, `🔴 ถูกยืมอยู่`, `🏷️ สำหรับขายเท่านั้น`, ป้ายสภาพ และราคา
2. **หน้ารายละเอียดหนังสือ (Book Detail Page)**:
   - แสดงรูปปกใหญ่, แกลเลอรีภาพตัวอย่าง (Thumbnails), ข้อมูลร้านค้าผู้ขาย, และป้ายรับรองสภาพหนังสือโดย BookShare
   - ตัวเลือกสลับระหว่าง **"ยืมอ่านประหยัด"** และ **"ซื้อขาดมือสอง"**
   - ปฏิทินเลือกวันเริ่มยืม-วันกำหนดคืน พร้อมปุ่มเลือกด่วน (7, 10, 14, 21 วัน) คำนวณค่ายืม + ค่ามัดจำอัตโนมัติ
3. **ระบบแยกตะกร้าสินค้า (Separated Cart)**:
   - **หมวด A: รายการที่จะเช่ายืม (Rental Items)** แสดงจำนวนวันยืม, กำหนดวันคืน, ค่ายืม, และเงินมัดจำ
   - **หมวด B: รายการที่จะซื้อขาด (Purchase Items)** แสดงราคาซื้อ, ราคาปกเดิม, และป้ายจัดส่งทันที
4. **การชำระเงินทีเดียว (Unified Checkout)**:
   - รวมยอดการเช่ายืมและซื้อขาดไว้ในใบสั่งซื้อเดียว
   - กล่องสรุปคำสั่งซื้อ: ค่ายืม + ค่าซื้อ + มัดจำ + ค่าจัดส่ง - ส่วนลด (`WELCOMEREAD`) = ยอดชำระสุทธิ
   - กล่องการันตีการคืนเงินมัดจำผ่านพร้อมเพย์ภายใน 24 ชม. และสถิติช่วยลดคาร์บอน
5. **เงื่อนไขบังคับความปลอดภัย (Mandatory Rules)**:
   - **ต้องล็อกอินเข้าสู่ระบบบัญชีก่อน** ถึงจะกดสั่งซื้อได้
   - **ต้องระบุที่อยู่จัดส่ง *(ข้อมูลบังคับ)*** หากยังไม่กรอก ระบบจะไม่อนุญาตให้กดชำระเงิน

## 🛠️ โครงสร้างโปรเจกต์ (Clean Structure)

```text
project/
├── app.py              # แอปพลิเคชันหลักภาษา Python (Streamlit)
├── index.html          # แอปพลิเคชันเว็บ Standalone (HTML + Tailwind CSS)
├── requirements.txt    # รายการไลบรารี Python (streamlit>=1.28.0)
├── .gitignore          # ละเว้นไฟล์ขยะและ cache ขึ้น Git
└── README.md           # คู่มือการติดตั้งและวิธีรัน
```

## 🚀 วิธีการรันโปรเจกต์ (How to Run)

### วิธีที่ 1: รันด้วย Streamlit (Python)
```bash
# 1. ติดตั้งไลบรารี
pip install -r requirements.txt

# 2. รันแอปพลิเคชัน
streamlit run app.py
```
เปิดเบราว์เซอร์ที่ `http://localhost:8501`

### วิธีที่ 2: รันผ่าน GitHub Pages (HTML)
1. นำไฟล์ขึ้น GitHub Repository
2. ไปที่ **Settings** > **Pages**
3. เลือก Branch: `main` และโฟลเดอร์: `/ (root)` แล้วกด **Save**
4. เปิดลิงก์ `https://<username>.github.io/<repo-name>/` ได้ทันที

### วิธีที่ 3: รันบน Streamlit Community Cloud
1. เข้าไปที่ [share.streamlit.io](https://share.streamlit.io/) ล็อกอินด้วย GitHub
2. กด **Create app** > เลือก Repository นี้ > ระบุ Main file path เป็น `app.py`
3. กด **Deploy!**
